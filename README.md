# Unit Testing - Reservations

Sample project to showcase how to unit test.

## Getting started

### Prerequisites

- [Node.js](https://nodejs.org/) 24 or later
- [pnpm](https://pnpm.io/)

### Install

```sh
pnpm install
```

### Run in development

Runs `src/app.ts` directly and restarts on file changes:

```sh
pnpm dev
```

### Build and run

Bundles the app into `dist/app.js` with esbuild, then runs it with Node:

```sh
pnpm build
pnpm start
```
